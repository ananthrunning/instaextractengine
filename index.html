Instagram Benchmark Builder

Turn an Instagram scrape into a ready-to-read Excel benchmark — no coding, no installs. Follow the three steps below once per pull, then drop the result in the tool at the bottom.

How it works

1

Run the scraper on Apify

Open apify.com/apify/instagram-post-scraper and sign in. Fill in the Input form:

  • Instagram username, profile URL, or post URL — one handle per line, e.g. necindiaofficial, no @
  • Maximum posts per profile — 200 is plenty
  • Extract posts that are newer than — 90 days (or whatever window you're comparing)
  • Skip pinned posts — leave checked

Click Start and wait — a handful of accounts usually takes under a minute.

2

Export the results

When the run finishes, click Export on the results screen. Choose format JSON, then Download. You'll get one .json file with every post from every handle you entered.

3

Build the Excel file, right here

Drop that .json file into the tool below. It reads it in your browser and downloads the finished workbook — nothing is uploaded anywhere, everything happens on your own machine.
